# PathForward Myanmar - Requirements

## System Requirements

### Required Software

1. Node.js
   - Version: 18.0.0 or higher
   - Download: https://nodejs.org/
   - Verify: node --version

2. Package Manager (Choose one)
   - npm (comes with Node.js)
   - pnpm (recommended for faster installs)
     Install: npm install -g pnpm

3. PostgreSQL
   - Version: 14.0 or higher
   - Download: https://www.postgresql.org/download/
   - Verify: psql --version

4. Git
   - Version: 2.0 or higher
   - Download: https://git-scm.com/
   - Verify: git --version

5. Code Editor (Recommended)
   - Visual Studio Code
   - Download: https://code.visualstudio.com/

## Database Setup

### PostgreSQL Installation

#### Windows
1. Download from: https://www.postgresql.org/download/windows/
2. Run installer
3. Set password for postgres user
4. Default port: 5432

#### Mac (using Homebrew)
```bash
brew install postgresql@14
brew services start postgresql@14
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
```

### Create Database
```bash
# Connect to PostgreSQL
psql -U postgres

# Create database
CREATE DATABASE pathforward_myanmar;

# Exit
\q
```

## Package Manager Comparison

### npm
- ✅ Comes with Node.js (no extra installation)
- ✅ Most common and widely supported
- ⚠️ Slower installation
- ⚠️ Larger disk space usage

### pnpm
- ✅ 2-3x faster installation
- ✅ Saves disk space (shared dependencies)
- ✅ More efficient package management
- ⚠️ Requires separate installation
- ⚠️ Less common (but growing)

**Recommendation**: Use pnpm for better performance, especially with multiple projects.

## Troubleshooting

### npm Installation Issues
```bash
# Clear npm cache
npm cache clean --force

# Remove node_modules and reinstall
rm -rf node_modules package-lock.json
npm install
```

### pnpm Installation Issues
```bash
# Clear pnpm cache
pnpm store prune

# Remove node_modules and reinstall
rm -rf node_modules pnpm-lock.yaml
pnpm install
```

### PostgreSQL Connection Issues
```bash
# Check if PostgreSQL is running
# Windows:
services.msc  # Look for postgresql service

# Mac:
brew services list

# Linux:
sudo systemctl status postgresql
```
